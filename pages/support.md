      # Hosting with support

      Managed hosting with a standing chat thread to the developer, your
      domain and email handled, and a site that stays yours to take away.
  - type: markdown
    content: |
      ## What the package adds

      Hosting with support is £40 a month. It includes everything managed
      hosting includes, and adds:

      - A chat thread with the developer that stays open while the package
        runs.
      - Domain and email handled. Chobble sets up your [custom
        domain](/features/custom-domain/), hosted email and Google Search
        Console.
      - Priority for feature requests. Chobble puts your requests ahead of
        the general queue, and does not guarantee that a request will be
        built.
  - type: markdown
    content: |
      ## Who it is for

      Standard hosting is for organisers happy to run the site themselves.
      This package is for the other case: you want the site set up, the
      domain pointed and the email flowing, and one person to message when
      something looks odd.

      The £40 buys the developer's time. Every feature is on every package,
      and there is no bigger product to unlock.
  - type: markdown
    content: |
      ## A site you can take away

      The hosted service runs the same open source product you can host
      yourself. You can download a complete database backup at any time
      ([backups](/features/backups/)), export your event setup as versioned
      JSON ([catalogue import and export](/features/catalogue-import-export/)),
      and move the whole thing to another Chobble Tickets host or
      [self-host](/features/deployment/) it with no licence fee
      ([open source](/features/open-source/)).

      A subscription site builder hosts your pages on its own platform.
      Here the site and its data stay exportable, so the support is worth
      having for as long as it is useful and the site leaves with you.
  - type: markdown
    content: |
      ## What does not change

      The package does not change the product. Ticket sales, capacity,
      refunds, encryption and exports work the same as on every hosted site,
      because there are no feature tiers.

      Support runs through the chat thread and email. There is no telephone
      support centre on any package.
  - type: markdown
    content: |
      ## What it costs

      The package is £40 a month. Charities, community groups, co-operatives
      and similar organisations pay £20 a month.

      Both rates bill monthly, in advance like all Chobble hosting. Managed
      hosting on its own costs £50 a year or £5 a month, and an organiser can
      move between the two arrangements.
  - type: markdown
    content: |
      ## Running this way

      [Chalkie's School for Dogs](https://www.chalkiesdogs.co.uk) runs its dog
      training classes on this package, from its own domain at
      chalkiesdogs.co.uk. The [examples page](/examples/) shows the site and
      what the arrangement covers in practice.
