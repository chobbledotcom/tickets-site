      # Chobble Tickets vs Rentman

      Rentman plans AV and event rental work, including inventory, crew, projects, quotes and invoices. Chobble Tickets offers a public booking page and checkout. Rentman also lists online payments and a webshop connection.
  - type: markdown
    content: |
      ## Open source and low cost Rentman alternative

      Rentman is planning software from Rentman B.V. in Utrecht, the
      Netherlands. It is used by AV and event rental companies to schedule
      equipment and crew, build quotes, run projects and invoice customers.
      It is a hosted service.

      Chobble Tickets is a booking and ticketing platform from a UK
      community interest company. It sells dated hire and events on a public
      page, collects payment and produces run sheets. It does not plan crew
      shifts, produce quotes or manage a warehouse.

      Rentman provides tools for internal planning and invoicing. Chobble
      Tickets provides a public booking page at a fixed price.

      ## Pricing comparison

      On 26 November 2026 the [Rentman pricing
      page](https://rentman.io/pricing) listed the platform at €39 a month,
      plus products priced per power user a month:

      | Product | Price per power user, per month |
      |---|---|
      | Inventory Standard | €14 |
      | Inventory Pro | €19 |
      | Crew Essential | €14 |
      | Crew Standard | €19 |
      | Crew Pro | €24 |
      | Organize Standard | €14 |
      | Quoting and invoicing | €9 |

      Yearly billing saves 8%. At the listed monthly rates, one power user
      with the platform, Inventory Standard and Quoting would pay €62 a
      month, or €744 over 12 months. Crew and Organize cost extra.

      Chobble Tickets is £50/year or £5/month, or £25/year or £2.50/month
      for charities, community groups, artists and musicians. There is no
      per-user fee and no Chobble charge per booking. Payment processing is
      separate.

      Rentman's products include crew scheduling, project planning and
      quotes. Chobble Tickets includes a public booking page, payments and
      run sheets.

      ## Data and hosting

      Rentman hosts project, crew and customer data. The pricing page
      reviewed does not document the source licence or say that customers
      can run Rentman on their own servers.

      Chobble Tickets encrypts personal data at rest and publishes its
      source. The operator can export the database and run the same code
      elsewhere, or self-host it. Chobble has no admin access to an
      organiser's site.
