      # Chobble Tickets vs EventPrime

      EventPrime is a WordPress plugin that adds an events calendar, bookings and ticket sales to an existing WordPress site. Chobble Tickets is a standalone ticketing platform. This page compares them on pricing, features and data handling.
  - type: markdown

      ## Open source & standalone EventPrime alternative

      [EventPrime](https://theeventprime.com/) is published by Metagauss Inc.
      The free core plugin is on WordPress.org, and paid features are sold as
      separate extensions or in plan bundles. Running it needs a WordPress
      site, hosting for that site, and updates for the plugin and each
      extension.

      Chobble Tickets is a standalone platform. You sign up at
      [tix.chobble.com](https://tix.chobble.com/ticket/register) or
      [self-host the code](/features/open-source/), and a
      [public website and CMS](/features/your-public-website/) is included, so
      on managed hosting there is nothing to install.

      Which one fits depends on whether ticketing should sit inside a
      WordPress site you already run, or work as its own product.

      ## What the licence covers

      The [Metagauss terms](https://metagauss.com/terms-and-conditions/) say
      support and updates last one year from purchase. After that you can keep
      using the version you have, or renew to keep receiving updates and
      support. Security fixes therefore stop arriving on an unrenewed licence.

      The unlimited-sites tiers carry a fair usage policy. Automatic access
      covers up to 20 websites, and further sites need a manual request that
      Metagauss can decline.

      Refunds are only given if negotiated before purchase or requested within
      24 hours of it. Metagauss also states that prices can change without
      notice.

      Chobble Tickets does not use per-site licensing, and updates and support
      continue for as long as you are a customer. Managed hosting is charged
      per site, so £50/year covers one hosted ticketing site and a second site
      is a second payment. The AGPL-3.0-only code can be self-hosted on any
      number of sites without a Chobble licence fee.

      ## Setup and hosting

      EventPrime is a plugin, not a hosted service. To sell tickets with it
      you need a WordPress site you host, the core plugin, the extensions or
      plan that covers the features you want, a payment gateway configured on
      the site, and ongoing updates for all of it.

      That suits an organiser who already runs WordPress, because events live
      in the admin they use every day and attendee records stay in their own
      database.

      Chobble Tickets hosted is the other trade-off. You sign up, log in and
      create an event, with no WordPress, no plugin updates and no server to
      patch. Attendee personal data is
      [encrypted at rest](/features/encrypted/), and the code can be
      [self-hosted](/hosting/) on infrastructure you select without a Chobble
      licence fee.

      ## Data and attendee privacy

      By default neither product sends attendee data to a third-party
      marketing database. EventPrime stores bookings in the organiser's own
      WordPress database, and Metagauss says it emails customers about
      updates, promotions and new features, with an opt-out. Those emails go
      to the licence holder, not to attendees.

      Organisers can change that by choice on either product. EventPrime's
      Mailchimp and MailPoet extensions subscribe attendees to the
      organiser's own lists, which sends their contact details to those
      services. Chobble Tickets sends confirmation emails through the
      [email provider the organiser configures](/features/email-providers/).
      In both cases the organiser picks the third party and the data goes to
      the organiser's own account with it.

      EventPrime's security is the security of the WordPress site it sits on.
      The booking records share a database with every other plugin and theme
      installed there, so a compromise elsewhere on the site can expose them.

      Chobble Tickets encrypts attendee personal data with the site's public
      key. Reading it needs the credentials of an authorised keyed user.
      Chobble does not run a marketplace and does not email attendees about
      other organisers' events.

      ## Who builds EventPrime?

      EventPrime is published by Metagauss Inc., which also sells the
      RegistrationMagic and ProfileGrid WordPress plugins. The free core
      plugin is listed on WordPress.org, where its current install count and
      rating are published. The Metagauss terms and conditions
      state that the agreement is governed by the law of the Province of
      Ontario, Canada.

      Chobble Tickets is run by one person as a
      [Community Interest Company](https://www.gov.uk/government/publications/community-interest-companies-introduction)

      Manchester. It is limited by guarantee and has no share capital, so
      there are no shares to buy and no dividends to pay. Under section 53 of
      the Companies (Audit, Investigations and Community Enterprise) Act 2004,
      a CIC can stop being a CIC only by dissolving or becoming a charity.
