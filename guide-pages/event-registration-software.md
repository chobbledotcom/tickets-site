    content: |
      Event registration software takes the sign-up rather than the
      sale. It collects who is coming, how many places they need and
      anything the organiser has to know in advance, then confirms the
      booking by email.

      Many events need both. A free talk needs only a registration, and a
      workshop charges for the place but still asks the questions. One
      tool doing both keeps a single list rather than two.
  - type: markdown
    dark: true
    content: |
      ## What a registration needs

      - A place limit on each session, so a free event does not overshoot
        the room
      - Questions such as dietary needs, access requirements or how
        someone heard about the event
      - A confirmation email with the joining details or a link to them
      - A booking cut-off before the event starts
      - A list the organiser can print, export or check people in from
      - Control over what contact details are collected, and when they
        are deleted

      ## How Chobble Tickets handles it

      A listing with no price works as a [sign-up form](/features/sign-up-forms/)
      with a place limit, questions and a confirmation email. No payment
      provider needs to be connected.

      [Custom questions](/features/custom-questions/) collect structured
      choices or free text at booking, and a group booking answers each
      question once. [Booking cut-offs and purchase
      limits](/features/registration-deadlines/) close registration
      before the event starts.

      When the event charges, the same listing sells places with all of
      the registration behaviour intact. Attendees receive a [QR code for
      check-in](/features/qr-code-check-ins/) and an [Apple Wallet or
      Google Wallet pass](/features/apple-wallet/).

      Contact details and answers are [encrypted in the
      database](/features/encrypted/), and a person's record can be
      [erased on request](/features/privacy-controls/). Chobble does not
      email attendees about other events or build audience profiles from
      their data.
