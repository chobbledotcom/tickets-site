  - type: markdown
    content: |
      Ticketing prices often contain several separate charges. This guide uses
      "no per-attendee fee" to mean that the ticketing provider does not add a
      mandatory percentage or fixed platform charge for each ticket sold.

      Card processors can still charge a percentage and a fixed amount for
      each payment transaction. One transaction can contain several tickets,
      so a payment-processing charge is not always a per-attendee charge.

      ## Self-installed ticketing software

      Self-installed software removes or replaces the provider's managed
      hosting charge. The organiser still pays for infrastructure, payment
      processing, email and any technical work needed to keep the service
      running.

      | Software | Software charge | Qualifications |
      |---|---|---|
      | [Chobble Tickets](/hosting/) | No Chobble software fee | The complete product can be self-hosted. Infrastructure and configured services cost extra. |
      | [Pretix Community](/compared-to/pretix/) | No licence fee for the Community edition | Core ticketing is open source. Proprietary enterprise plugins start at €499/year, and the operator maintains the server and database. |
      | [alf.io](/compared-to/swicket/) | No software fee | Open source software with no per-ticket platform fee. The operator pays for infrastructure and processing. |
      | [Hi.Events](/compared-to/hi-events/) | No platform fee when self-hosted | Free use requires visible "Powered by Hi.Events" branding. A Single Domain commercial licence removes it for $499 or more. |
      | [FooEvents](/compared-to/fooevents/) | Core plugin from $69/year; bundles from $139/year | The WordPress and WooCommerce plugin takes no commission or per-ticket fee. WordPress hosting, the plugin subscription and payment processing remain separate. |
      | [Event Schedule](/compared-to/event-schedule/) | No licence fee (Attribution Assurance License) | Open source with no per-ticket platform fee. The hosted plans are tiered by feature, and the operator maintains the server. |
      | [Revel](/compared-to/revel/) | No software fee when self-hosted (MIT) | Self-hosting takes no per-ticket fee. The Revel-hosted service charges 3% + €0.50 per paid ticket, and the operator maintains the server. |
      | [libreevent](/compared-to/libreevent/) | No software fee (GPLv3) | No per-ticket fee. The project is archived, so the operator maintains their own copy of the code and the server. |
      | [EventPrime](/compared-to/eventprime/) | Free core plugin (GPLv2 or later); paid extensions separate | The WordPress plugin takes no per-ticket fee. WordPress hosting, paid extensions and payment processing remain separate. |
      | [EventMS Pro](/compared-to/eventms-pro/) | One-time licence of $4,999 (early-bird) or $7,999 | A closed self-hosted build with no per-ticket fee or revenue share, but a large one-time software cost. The operator maintains the server. |

      Several of these publish their source code. The
      [open source ticketing platforms guide](/guide/choosing-a-ticket-platform/open-source-ticketing-platforms/)
      compares their licences and how each can be self-hosted.

      ## Options with volume conditions

      Some providers advertise no percentage commission but still make the
      price depend on booking or ticket volume. They are not included in the
      strict lists above.

      - [Resova](/compared-to/resova/) has no percentage commission, but each
        monthly plan includes a booking allowance and then charges for extra
        bookings. Its custom-priced Enterprise plan lists unlimited bookings.
      - [Tessera Tickets](/compared-to/tessera-tickets/) takes no cut from each
        ticket, but its monthly subscription tiers rise with annual ticket
        volume.
      - [Ticket Tailor](/compared-to/ticket-tailor/) charges no percentage, but
        it does charge a fixed amount for each paid ticket.
      - [Cal.com](/compared-to/cal-com/)'s free Individual plan includes
        unlimited meetings and Stripe or PayPal payments, but it is scheduling
        software rather than a complete event-ticketing service.

  - type: markdown

      ## Costs to check

      - Annual or monthly software subscriptions
      - Fixed and percentage platform fees
      - Payment-processing charges per transaction
      - Buyer-paid booking fees
      - Ticket-volume tiers and booking allowances
      - VAT, currency conversion and refund charges
      - Hosting, email, maintenance and support for self-installed software

      The [platform fee calculator](/compared-to/compare-all/) compares the
      documented prices for Chobble Tickets and other hosted providers. Its
      fixed-cost examples assume one ticket per payment transaction, so an
      organiser should also test the usual number of tickets in each order.
